# Skill — User Research : Fabula

> Projet : Fabula
> Type : Side project

---

## Quand utiliser

Utiliser ce skill à chaque fois qu'une décision produit majeure doit être prise, qu'un nouveau jalon est planifié, ou qu'un doute persiste sur la pertinence d'une fonctionnalité pour les créateurs d'histoires.

---

## Inputs attendus

- Hypothèse ou fonctionnalité à valider
- Profil(s) cible(s) concerné(s) (écrivain, scénariste, MJ, game designer)
- Type de recherche : interview qualitative, questionnaire, test utilisateur, ou analyse de feedback existant

---

## Checklist de recherche utilisateur

### 1. Préparer la recherche
- [ ] Définir l'objectif de la recherche (quelle hypothèse valider ?)
- [ ] Choisir le format adapté (interview 30 min, questionnaire en ligne, test A/B)
- [ ] Identifier 3 à 5 profils représentatifs
- [ ] Rédiger le guide d'interview ou le questionnaire (max 10 questions)

### 2. Conduire la recherche
- [ ] Contacter les participants avec un contexte clair
- [ ] Poser des questions ouvertes sur leurs outils actuels et leurs frustrations
- [ ] Leur présenter des maquettes ou des descriptions de features si pertinent
- [ ] Noter verbatim les réponses et observer les comportements

### 3. Synthétiser
- [ ] Extraire les 3 points de douleur majeurs
- [ ] Identifier les fonctionnalités les plus demandées ou rejetées
- [ ] Classer les retours par profil utilisateur
- [ ] Formuler des recommandations actionnables pour `@fabula-main`

---
